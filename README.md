# Як запустити сайт — інструкція для «чайника»

Займе ~20 хвилин. Потрібні лише браузер і пошта.

━━━━━━━━━━━━━━━━━━━━━━━━━━
## КРОК 1. Розпакуйте архів
━━━━━━━━━━━━━━━━━━━━━━━━━━
Знайдіть завантажений zip → правою кнопкою → «Видобути все» (на Mac — двічі клікнути).
З'явиться папка. Всередині: index.html, content.json, support.js, папки im і admin.

━━━━━━━━━━━━━━━━━━━━━━━━━━
## КРОК 2. GitHub — «сховище» для сайту
━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Відкрийте github.com → «Sign up» → зареєструйтесь (пошта + пароль).
2. Вгорі праворуч «+» → «New repository».
3. Repository name: illia-site → оберіть «Private» → «Create repository».
4. На наступній сторінці натисніть посилання «uploading an existing file».
5. Відкрийте розпаковану папку, виділіть УСЕ всередині (Ctrl+A / Cmd+A)
   і перетягніть у вікно браузера.
6. Дочекайтесь, поки все завантажиться → внизу зелена кнопка «Commit changes».

✅ Перевірка: у репозиторії видно папки admin, im і файл index.html.

━━━━━━━━━━━━━━━━━━━━━━━━━━
## КРОК 3. Netlify — робимо сайт видимим в інтернеті
━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Відкрийте netlify.com → «Sign up» → «Sign up with GitHub» → дозволити.
2. «Add new site» (або «Add new project») → «Import an existing project» → «GitHub».
3. Оберіть illia-site (якщо не видно — натисніть «Configure Netlify on GitHub» і дайте доступ).
4. Всі поля залиште як є (порожні) → «Deploy».
5. Через хвилину з'явиться адреса типу  something-123.netlify.app — це ваш сайт!

💡 Змінити адресу: Site configuration → «Change site name» → напр. illia-zhulevych
   → сайт буде illia-zhulevych.netlify.app

━━━━━━━━━━━━━━━━━━━━━━━━━━
## КРОК 4. Вмикаємо адмінку для Іллі
━━━━━━━━━━━━━━━━━━━━━━━━━━
У Netlify, на сторінці вашого сайту:
1. Ліве меню → «Identity» (або Project configuration → Identity) → «Enable Identity».
2. Там же → «Registration» → обрати «Invite only» → Save.
   (щоб ніхто сторонній не зареєструвався)
3. Там же нижче → «Services» → «Git Gateway» → «Enable».
4. Вгорі вкладка «Identity» → «Invite users» → впишіть пошту Іллі → Send.
5. Ілля відкриває лист → натискає посилання → придумує пароль.

✅ Готово. Адмінка: ваш-сайт.netlify.app/admin

━━━━━━━━━━━━━━━━━━━━━━━━━━
## ЯК ІЛЛІ ЩОСЬ ЗМІНИТИ
━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Відкрити ваш-сайт.netlify.app/admin → увійти.
2. «Сайт» → «Весь контент сайту».
3. Блоки йдуть як на сайті: Головний екран, Цифри, Рілси, Портфоліо…
   Клікнути на потрібний → змінити текст / «Choose image» для фото.
4. Вгорі «Publish» → «Publish now».
5. Через 1–2 хвилини зміни на сайті (оновіть сторінку).

▶ Додати рілс: «Рілси» → «Add» → вставити посилання з Instagram
  (в Instagram: ⋯ під рілсом → «Копіювати посилання»).
▶ Додати Telegram / телефон: блок «Контакти» → вписати → Publish.
  Поки поле порожнє — на сайті його не видно.
▶ Приховати відгуки: «Відгуки» → вимкнути «Показувати блок».

━━━━━━━━━━━━━━━━━━━━━━━━━━
## ЯКЩО ЩОСЬ НЕ ТАК
━━━━━━━━━━━━━━━━━━━━━━━━━━
• Сайт білий/порожній, якщо відкрити index.html з комп'ютера — це нормально.
  Він працює тільки на Netlify.
• Немає пункту «Identity» в Netlify — напишіть мені, переключу адмінку
  на вхід через GitHub (2 хвилини роботи).
• Зміни не з'явились — зачекайте 2 хв і оновіть сторінку (Ctrl+F5).
